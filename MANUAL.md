## 1. О программе

`geant4-autoradiolysis-beta` — программа для моделирования **авторадиолиза β-распадчиков в жидкой среде**: она рассчитывает, какую поглощённую дозу получает жидкая среда (вода) в цилиндрической ёмкости от собственного радионуклида, растворённого в ней, на движке Geant4.

В программе реализованы **два независимых пути расчёта поглощённой дозы**:

| Путь | Что считает |
|---|---|
| **Path A** | Энерговыделение (energy deposit) — по трекам вторичных частиц в чувствительном объёме жидкости |
| **Path B** | Энергетический баланс распада — по разности рождённой энергии и энергии, покинувшей объём |

Согласованность путей контролируется полем **Cross-check (A−B)**: его значение должно быть близко к нулю (на много порядков меньше, чем результаты расчёта) — это подтверждает, что энергетический баланс сходится.

Программа состоит из двух частей:

| Файл | Назначение |
|---|---|
| `build\Release\main.exe` | расчётная часть (C++/Geant4) |
| `program_b.py` | графический интерфейс: выбор параметров, запуск, просмотр результатов (Python/tkinter) |

Пользователь работает в основном с графическим интерфейсом; `main.exe` запускается из него автоматически.

Что входит в архив релиза:

```
geant4-autoradiolysis-beta-v0.1.0-win64\
├── build\Release\main.exe   — расчётная часть
├── program_b.py              — графический интерфейс
├── start.bat                 — запуск программы с проверкой установки
├── interactive.bat           — запуск интерактивного режима Geant4
├── vis.mac, gui.mac          — макросы визуализации и меню
├── MANUAL.docx               — это руководство в формате Word
└── README.txt                — краткая справка
```

## 3. Установка Geant4

1. Откройте в браузере страницу загрузки: <https://geant4.web.cern.ch/download/11.4.1>

   > **[Скриншот: страница загрузки Geant4 в браузере]**
   > *— страница geant4.web.cern.ch/download/11.4.1, виден раздел Binary releases и кнопка Download exe в строке Windows.*

2. Скачайте установщик **Windows, Visual Studio Code** → кнопка **Download exe**
   (прямая ссылка: <https://cern.ch/geant4-data/releases/lib4.11.4.p01/WIN64-VC17.11.4-11.exe>). Файл большой — скачивание может занять продолжительное время.

3. Запустите скачанный файл установщика. Дальше отвечайте «Далее» (Next) на все вопросы установщика.

4. **Единственное, на что стоит обратить внимание, — каталог установки.** Укажите простой путь без пробелов и без кириллицы, например:

   ```text
   C:\Geant4\geant4_11.4.1
   ```

   > **[Скриншот: окно установщика Geant4 с выбором каталога]**
   > *— шаг установки, где вводится путь C:\Geant4\geant4_11.4.1.*

5. Состав компонентов оставьте по умолчанию. Примеры (Examples) можно отключить — они не нужны.

6. Дождитесь завершения установки и нажмите Finish.

Установщик **сам** настраивает систему: добавляет Geant4 в PATH и создаёт все необходимые переменные с данными распадов. Ничего дописывать вручную не нужно.

**После установки Geant4 рекомендуется перезагрузить компьютер** — это гарантирует, что все изменения вступят в силу.

## 4. Установка Python и зависимостей

### 4.1. Установка Python

1. Откройте в браузере страницу: <https://www.python.org/downloads/windows/>
2. Скачайте самую свежую версию **Windows installer (64-bit)**.
3. Запустите установщик.
4. **Обязательно включите галочку внизу окна: «Add python.exe to PATH»** — без неё программа не сможет найти Python.

   > **[Скриншот: окно установщика Python с галочкой Add python.exe to PATH]**
   > *— первое окно установщика, внизу отмечена галочка «Add python.exe to PATH», затем нажата кнопка «Install Now».*

5. Нажмите **Install Now** и дождитесь завершения.

### 4.2. Открываем командную строку

Для установки одной библиотеки (matplotlib) понадобится командная строка — это чёрное окно, куда вводятся текстовые команды. Открывается она так:

1. Нажмите на клавиатуре **Win + R** (клавиша Windows и буква R одновременно).
2. В появившемся маленьком окне «Выполнить» введите слово `cmd` и нажмите **Enter**.

   > **[Скриншот: окно «Выполнить» с введённой командой cmd]**
   > *— окно Win+R, в поле «Открыть» набрано cmd.*

3. Откроется чёрное окно командной строки — оно понадобится только на несколько минут.

   > **[Скриншот: окно командной строки]**
   > *— пустое чёрное окно с приглашением C:\Users\...>*

### 4.3. Проверка, что Python установлен

В командной строке введите (можно скопировать и вставить) и нажмите Enter:

```bat
py --version
```

Должно появиться что-то вроде:

```text
Python 3.14.5
```

Любая версия 3.12 или новее подходит. Если написано `Python 3.11.x` или старше — скачайте и переустановите Python, не забыв про галочку «Add python.exe to PATH».

Если появилось сообщение «'py' не является внутренней или внешней командой» — галочка «Add python.exe to PATH» не была отмечена. Переустановите Python с этой галочкой и снова проверьте.

### 4.4. Установка matplotlib

Программе нужна библиотека **matplotlib** — она рисует графики бета-спектров на вкладке «Спектры». Всё остальное работает и без неё, но в полной комплектации её лучше поставить сразу.

Всё в том же окне командной строки выполните:

```bat
py -m pip install matplotlib
```

Дождитесь завершения (в конце должна появиться строчка `Successfully installed matplotlib-...`). Проверьте:

```bat
py -c "import matplotlib; print(matplotlib.__version__)"
```

Должна напечататься версия, например `3.10.9`.

### 4.5. Закройте командную строку

Окно командной строки можно закрыть — оно больше не понадобится.

## 5. Скачивание и запуск программы

### 5.1. Скачивание

Страница релизов: <https://github.com/timishavet/geant4-autoradiolysis-beta/releases>

Скачайте файл текущего релиза:

```text
geant4-autoradiolysis-beta-v0.1.0-win64.zip
```

### 5.2. Распаковка

1. Найдите скачанный архив в Проводнике (обычно это папка «Загрузки»).
2. Нажмите на архив **правой кнопкой мыши** → **«Извлечь всё»** → укажите, куда распаковать, например `C:\geant4-autoradiolysis-beta` → нажмите «Извлечь».

   > **[Скриншот: контекстное меню архива в Проводнике с пунктом «Извлечь всё»]**

3. После распаковки откроется папка с содержимым. Должны быть видны файлы `start.bat`, `program_b.py` и папка `build`.

   > **[Скриншот: распакованная папка в Проводнике]**
   > *— видны start.bat, program_b.py, папка build и остальные файлы.*

Если внутри окажется ещё одна вложенная папка — просто зайдите в неё.

### 5.3. Запуск

**Дважды щёлкните по файлу `start.bat`.**

При первом запуске Windows может показать предупреждение «Windows защищена от запуска незнакомых приложений» — нажмите «Всё равно запустить» (этот файл — часть программы, он безопасен).

Что делает `start.bat`:

1. Проверяет, что установлен Python.
2. Проверяет, что Python собран с tkinter (нужен для окон интерфейса).
3. Проверяет, что установлен matplotlib.
4. Проверяет, что установлен Geant4 и он прописан в системе.
5. Проверяет, что в системе есть данные распадов Geant4.
6. Проверяет, что файл `build\Release\main.exe` на месте (архив распакован полностью).

Если **всё в порядке** — молча открывается окно программы «Программа Б — Генератор макросов». Если что-то не нашлось — `start.bat` напишет, чего именно не хватает и что сделать (список сообщений — в разделе 7).

   > **[Скриншот: окно «Программа Б — Генератор макросов»]**
   > *— окно программы, видны вкладки: Геометрия, Среда и материалы, Радионуклид, Распад, Получаемые значения, Запуск и вывод, Спектры.*

## 6. Программа: устройство и пример расчёта

### 6.1. Вкладки программы

| Вкладка | Что настраивается |
|---|---|
| Геометрия | форма ёмкости (цилиндр, стакан, пробирка), радиус, высота, толщина стеклянной стенки, сухой бортик |
| Среда и материалы | материал жидкости и стекла, их плотности |
| Радионуклид | выбор радионуклида; показываются период полураспада T½ и наличие данных Geant4 |
| Распад | режим расчёта: по числу распадов или по активности и времени облучения |
| Получаемые значения | какие поля выводить в результаты |
| Запуск и вывод | запуск симуляции, прогресс, просмотр результатов |
| Спектры | графики бета-спектров |

### 6.2. Пример: Lu-177 в стакане

Разберём полный расчёт: сколько поглощённой дозы получает вода в стакане от растворённого в ней Lu-177 (β⁻-излучатель, E_βmax ≈ 497 кэВ, один из основных нуклидов таргетной радиотерапии).

**Шаг 1 — Геометрия.** На вкладке «Геометрия»:

- Вариант ёмкости: **Стакан**
- Радиус: 2 см, Высота: 6 см (значения по умолчанию)
- Толщина стенки: 1,5 мм, Сухой бортик: 0 мм (по умолчанию)

Программа сразу покажет объём жидкости — для этих размеров 75,3982 см³.

**Шаг 2 — Среда и материалы.** Оставляем по умолчанию: жидкость — вода (G4_WATER, 1,000 г/см³), оболочка — стекло (SiO₂, 2,320 г/см³).

**Шаг 3 — Радионуклид.** На вкладке «Радионуклид» выберите из списка **Lu-177**. Программа покажет период полураспада (T½ ≈ 6,647 сут) и сообщение «Схема распада есть. Уровни дочерних есть.» — значит, данные Geant4 на месте.

**Шаг 4 — Распад.** Режим: **по числу распадов**, количество: `100000`.

**Шаг 5 — Запуск.** Вкладка «Запуск и вывод» → кнопка **«Запустить симуляцию»**. Следите за прогресс-баром. Для ста тысяч распадов на обычном компьютере требуется меньше секунды.

**Шаг 6 — Результаты.** После завершения внизу появится блок результатов (примерный вид; точные числа будут отличаться, так как генератор случайных чисел каждый раз другой):

### 6.3. Как читать результаты

| Поле | Что означает |
|---|---|
| `Number of decays` | сколько распадов просчитано — должно совпадать с заданным |
| `Volume`, `Material mass` | объём и масса жидкой среды — проверьте, что это ваши размеры |
| `Energy deposit (A)` | энергия, поглощённая жидкостью по Path A, МэВ |
| `Absorbed dose (A)` | **поглощённая доза по Path A, Гр (Грей)** — основной результат расчёта |
| `Decay energy (B)` | полная энергия, выделившаяся при всех распадах (вход в баланс), МэВ |
| `Escaped energy (B)` | энергия, убежавшая из объёма жидкости (бета-частицы и γ уходят в стекло и наружу), МэВ |
| `Transferred (B)` | энергия, оставшаяся в жидкости по балансу (выход из баланса), МэВ |
| `Absorbed dose (B)` | поглощённая доза, посчитанная по Path B, Гр |
| `Cross-check (A-B)` | расхождение двух путей, МэВ. **Должно быть ≈ 0** — это ключевая проверка корректности: два независимых метода дали одинаковый результат |
| `Energy per decay` | средняя поглощённая энергия на один распад, МэВ |

Физический смысл: из `Decay energy (B)` и `Escaped energy (B)` видно, что бо́льшая часть энергии распада Lu-177 уходит из объёма жидкости — это ожидаемо, так как бета-частицы с E_βmax ≈ 497 кэВ имеют пробег в воде около миллиметра и легко покидают объём даже при сантиметровых размерах ёмкости. Поглощённая доза при 10⁵ распадов в 75 см³ воды — порядка 10⁻⁸ Гр.

### 6.4. Где сохраняются результаты

- В окне программы на вкладке «Запуск и вывод».
- В файле `results.txt` в папке программы — каждый запуск **дописывается** в конец файла, так что `results.txt` хранит историю всех расчётов.
- Рядом могут создаваться `beta_minus.txt` и `beta_plus.txt` — энергии бета-частиц, если на вкладке «Спектры» включена запись спектров.

## 7. Если что-то пошло не так

### 7.1. Сообщения start.bat

| Сообщение | Что сделать |
|---|---|
| `не найден Python` | Установите Python 3.12+ с <https://www.python.org/downloads/windows/>, включив «Add python.exe to PATH» (раздел 4.1) |
| `Python установлен без компонента tkinter` | Переустановите Python: запустите установщик повторно → «Modify» → включите «tcl/tk and IDLE» |
| `не установлен пакет matplotlib` | Откройте командную строку (Win+R, `cmd`) и выполните `py -m pip install matplotlib` (раздел 4.4) |
| `не найден Geant4` | Установите Geant4 11.4.1 (раздел 3), после установки перезагрузите компьютер |
| `не найдены данные распадов Geant4 (G4RADIOACTIVEDATA)` | Переустановите Geant4 11.4.1 — установщик создаёт эти данные сам |
| `не найден файл build\Release\main.exe` | Архив распакован не полностью — распакуйте заново (раздел 5.2) |

После исправления просто запустите `start.bat` ещё раз.

### 7.2. Окно программы открылось, но что-то не так

| Ситуация | Причина и решение |
|---|---|
| Ошибка «Illegal application state» при запуске по своему макросу | Команды настройки геометрии и радионуклида должны стоять **до** строки `/run/initialize` |
| На вкладке «Радионуклид» написано, что данных Geant4 нет | Для этого нуклида в вашей установке Geant4 нет схемы распада — выберите другой нуклид из списка |
| Программа «зависла» на прогресс-баре | Возможно, задано очень много распадов — подождите или нажмите «Остановить симуляцию» и уменьшите число распадов |
| Окно start.bat открывается и тут же закрывается | Запустите start.bat через правую кнопку мыши → «Запуск от имени администратора»; если не помогло — сообщите текст ошибки из окна |

## 8. Приложение для опытных пользователей

Разделы ниже не нужны для обычной работы; они пригодятся, если потребуется запускать расчёты без интерфейса или разбираться в устройстве установки Geant4.

### 8.1. Пакетный режим (без графического интерфейса)

`main.exe` умеет работать по файлу-макросу:

```bat
build\Release\main.exe run.mac
```

Файл `run.mac` создаётся графическим интерфейсом автоматически при каждом запуске (его также можно сохранить кнопкой «Сохранить .mac»). Основные команды макроса:

```text
/myDetector/setGeometry        cylinder | beaker | tube
/myDetector/setRadius          2 cm
/myDetector/setHalfHeight      3 cm
/myDetector/setGlassWall       0.15 cm
/myDetector/setRim             0 cm
/myDetector/setGlassMaterial   G4_SILICON_DIOXIDE
/myDetector/setMaterial        G4_WATER
/mySource/setRadionuclide      71 177
/myOutput/enableAll
/mySpectrum/enable
/run/initialize
/process/had/rdm/thresholdForVeryLongDecayTime 1.0e+60 year
/run/beamOn 100000
```

Важно: команды `/myDetector/*` и `/mySource/setRadionuclide` должны стоять **до** `/run/initialize`.

### 8.2. Интерактивный режим с визуализацией

```bat
interactive.bat
```

или запустите `main.exe` без аргументов — откроется меню Geant4 с визуализацией геометрии (нужна поддержка OpenGL). Запускайте из папки программы: макросы `vis.mac` и `gui.mac` ищутся в текущем каталоге.

### 8.3. Переменные G4*DATA

Установщик Geant4 11.4.1 создаёт переменные окружения `G4*DATA` автоматически. Этот раздел нужен только для понимания, что это и где посмотреть.

Переменные окружения — это записи в системе Windows, которые указывают программам, где лежат файлы. Программе важны две из них: `G4RADIOACTIVEDATA` (схемы распада) и `G4LEVELGAMMADATA` (уровни дочерних ядер).

Посмотреть их можно вручную:

1. Нажмите **Win + R**, введите `sysdm.cpl`, нажмите Enter.
2. Вкладка «Дополнительно» → кнопка «Переменные среды…».
3. В блоке «Системные переменные» найдите `G4RADIOACTIVEDATA` — её значением должен быть путь вида `...\share\Geant4\data\RadioactiveDecay6.1.2`.

   > **[Скриншот: окно «Переменные среды» с подсвеченной G4RADIOACTIVEDATA]**

Если переменной нет — переустановите Geant4. Править переменные вручную можно, но при недоступности путей программа будет выдавать ошибки; надёжнее переустановить Geant4 стандартным установщиком.

### 8.4. Обновление и удаление

**Обновление:** скачайте новый архив релиза, распакуйте его поверх папки программы, заменив файлы. Файлы `run.mac` и `results.txt` при обновлении можно сохранить.

**Удаление:** просто удалите папку программы. Установленные Geant4, Python и matplotlib удаляются стандартными средствами Windows («Приложения»), если они больше не нужны.
