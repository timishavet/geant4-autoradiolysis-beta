## 1. О программе

`geant4-autoradiolysis-beta` — программа для моделирования **авторадиолиза β-распадчиков в жидкой среде**: она рассчитывает, какую поглощённую дозу получает жидкая среда в ёмкости от собственного радионуклида, равномерно растворённого в ней, на движке Geant4.

В программе реализованы **два независимых пути расчёта поглощённой дозы**:

| Путь | Что считает |
|---|---|
| **Path A** | Энерговыделение по трекам вторичных частиц в чувствительном объёме жидкости |
| **Path B** | Энергетический баланс распада по разности выделившейся в результате распада энергии и энергии, покинувшей объём |

Согласованность путей контролируется полем **Cross-check (A−B)**: его значение должно быть близко к нулю (на много порядков меньше, чем результаты расчёта) — это подтверждает, что энергетический баланс сходится.

Программа состоит из двух частей:

| Файл | Назначение |
|---|---|
| `build\Release\main.exe` | расчётная часть (C++/Geant4) |
| `program_b.py` | графический интерфейс: выбор параметров, запуск, просмотр результатов (Python/tkinter) |

Пользователь работает в основном с графическим интерфейсом; `main.exe` запускается из него автоматически.

Что входит в архив релиза:

```
geant4-autoradiolysis-beta-v0.1.0-win64\
├── build\Release\main.exe   — расчётная часть
├── program_b.py              — графический интерфейс
├── start.bat                 — запуск программы с проверкой установки
├── install_data.bat          — установка пакетов данных Geant4 (запускается один раз)
├── interactive.bat           — запуск интерактивного режима Geant4
├── vis.mac, gui.mac          — макросы визуализации и меню
├── MANUAL.docx               — это руководство в формате Word
└── README.txt                — краткая справка
```

## 3. Скачивание и распаковка программы

Начнём с самой программы: её нужно скачать и распаковать, чтобы потом положить рядом пакеты данных и запускать расчёты. Дальше — Python (раздел 4), затем Geant4 (раздел 5).

### 3.1. Скачивание

Страница релизов: <https://github.com/timishavet/geant4-autoradiolysis-beta/releases>

Скачайте архив текущего релиза. Название файла — вида `geant4-autoradiolysis-beta-vX.Y.Z-win64.zip` (например, `geant4-autoradiolysis-beta-v0.1.0-win64.zip`).

### 3.2. Распаковка

1. Найдите скачанный архив в Проводнике (обычно это папка «Загрузки»).
2. Нажмите на архив **правой кнопкой мыши** → **«Извлечь всё»** → укажите, куда распаковать, например `C:\geant4-autoradiolysis-beta` → нажмите «Извлечь».

   > **[Скриншот: контекстное меню архива в Проводнике с пунктом «Извлечь всё»]**

3. После распаковки откроется папка с содержимым. Должны быть видны файлы `start.bat`, `install_data.bat`, `program_b.py` и папка `build`.

   > **[Скриншот: распакованная папка в Проводнике]**
   > *— видны start.bat, install_data.bat, program_b.py, папка build и остальные файлы.*

Если внутри окажется ещё одна вложенная папка — просто зайдите в неё.

Дальше — установите Python (раздел 4), затем Geant4 (раздел 5).

## 4. Установка Python и зависимостей

### 4.1. Установка Python

1. Откройте в браузере страницу: <https://www.python.org/downloads/windows/>
2. Скачайте самую свежую версию **Windows installer (64-bit)**.
3. Запустите установщик.
4. **Обязательно включите галочку внизу окна: «Add python.exe to PATH»** — без неё программа не сможет найти Python.

   > **[Скриншот: окно установщика Python с галочкой Add python.exe to PATH]**
   > *— первое окно установщика, внизу отмечена галочка «Add python.exe to PATH», затем нажата кнопка «Install Now».*

5. Нажмите **Install Now** и дождитесь завершения.

### 4.2. Открываем командную строку

Для установки одной библиотеки (matplotlib) понадобится командная строка — это чёрное окно, куда вводятся текстовые команды. Открывается она так:

1. Нажмите на клавиатуре **Win + R** (клавиша Windows и буква R одновременно).
2. В появившемся маленьком окне «Выполнить» введите слово `cmd` и нажмите **Enter**.

   > **[Скриншот: окно «Выполнить» с введённой командой cmd]**
   > *— окно Win+R, в поле «Открыть» набрано cmd.*

3. Откроется чёрное окно командной строки — оно понадобится только на несколько минут.

   > **[Скриншот: окно командной строки]**
   > *— пустое чёрное окно с приглашением C:\Users\...>*

### 4.3. Проверка, что Python установлен

В командной строке введите (можно скопировать и вставить) и нажмите Enter:

```bat
py --version
```

Должно появиться что-то вроде:

```text
Python 3.14.5
```

Любая версия 3.12 или новее подходит. Если написано `Python 3.11.x` или старше — скачайте и переустановите Python, не забыв про галочку «Add python.exe to PATH».

Если появилось сообщение «'py' не является внутренней или внешней командой» — галочка «Add python.exe to PATH» не была отмечена. Переустановите Python с этой галочкой и снова проверьте.

### 4.4. Установка matplotlib

Программе нужна библиотека **matplotlib** — она рисует графики бета-спектров на вкладке «Спектры». Всё остальное работает и без неё, но в полной комплектации её лучше поставить сразу.

Всё в том же окне командной строки выполните:

```bat
py -m pip install matplotlib
```

Дождитесь завершения (в конце должна появиться строчка `Successfully installed matplotlib-...`). Проверьте:

```bat
py -c "import matplotlib; print(matplotlib.__version__)"
```

Должна напечататься версия, например `3.10.9`.

### 4.5. Закройте командную строку

Окно командной строки можно закрыть — оно больше не понадобится.

Дальше — установка Geant4 (раздел 5).

## 5. Установка Geant4

Geant4 — это движок расчётов: набор библиотек и вспомогательных файлов, к которым обращается программа. Ставится один раз.

### 5.1. Установка Geant4

1. Откройте в браузере страницу загрузки: <https://geant4.web.cern.ch/download/11.4.1>

   > **[Скриншот: страница загрузки Geant4 в браузере]**
   > *— страница geant4.web.cern.ch/download/11.4.1, виден раздел Binary releases и кнопка Download exe в строке Windows.*

2. Скачайте установщик для Windows: в таблице **Binary releases** найдите строку **Windows 11, Visual Studio Code-17.11.4** и нажмите **Download exe** (файл `WIN64-VC17.11.4-11.exe`). Название с Visual Studio Code относится к компилятору Microsoft Visual C++ 17.11.4, на котором собраны библиотеки Geant4; сам редактор VS Code устанавливать не нужно — в пакете только Geant4.

3. Запустите скачанный файл установщика. Дальше отвечайте «Далее» (Next) на все вопросы установщика.

4. **На что обратить внимание — каталог установки.** Укажите простой путь без пробелов и без кириллицы, например:

   ```text
   C:\Geant4
   ```

   > **[Скриншот: окно установщика Geant4 с выбором каталога]**
   > *— шаг установки, где вводится путь C:\Geant4.*

5. **В одном из окон установщика есть предложение добавить Geant4 в переменные системы Windows (PATH) — обязательно отметьте его.** Без этой опции система не узнает, где стоит Geant4, и программа его не найдёт.

   > **[Скриншот: окно установщика Geant4 с опцией добавления в PATH]**
   > *— шаг установки, отмечена опция добавления Geant4 в PATH.*

6. Состав компонентов оставьте по умолчанию.

7. Дождитесь завершения установки и нажмите Finish.

**После полной установки перезагрузите компьютер** — это гарантирует, что все изменения (в том числе PATH) вступят в силу.

### 5.2. Установка пакетов данных Geant4

Geant4 работает не сама — ей нужны таблицы физических данных: схемы распада, уровни дочерних ядер, сечения взаимодействий частиц. Они распространяются отдельными пакетами.

**Что скачать.** Для работы программы критичны пять пакетов (версии указаны для Geant4 11.4.1):

| Пакет | Ссылка для скачивания |
|---|---|
| G4EMLOW.8.8 | <https://cern.ch/geant4-data/datasets/G4EMLOW.8.8.tar.gz> |
| G4RadioactiveDecay.6.1.2 | <https://cern.ch/geant4-data/datasets/G4RadioactiveDecay.6.1.2.tar.gz> |
| G4PhotonEvaporation.6.1.2 | <https://cern.ch/geant4-data/datasets/G4PhotonEvaporation.6.1.2.tar.gz> |
| G4ENSDFSTATE.3.0 | <https://cern.ch/geant4-data/datasets/G4ENSDFSTATE.3.0.tar.gz> |
| G4PARTICLEXS.4.2 | <https://cern.ch/geant4-data/datasets/G4PARTICLEXS.4.2.tar.gz> |

Полный список пакетов Geant4 (остальные для работы программы не обязательны) — на странице <https://geant4.web.cern.ch/download/11.4.1.html>, раздел **Datasets**.

**Порядок действий:**

1. Скачайте пять файлов из таблицы выше — по каждой ссылке браузер начнёт загрузку файла `.tar.gz`.
2. Положите скачанные файлы **рядом с `install_data.bat`** — то есть в папку программы (туда, где лежат `start.bat` и `program_b.py`). В папке «Загрузки» их оставлять не нужно.
3. Дважды щёлкните по файлу `install_data.bat` — он распакует пакеты в папку `<каталог Geant4>\data` (она создаётся автоматически) и сам пропишет переменные среды Windows. При первом запуске Windows может показать предупреждение «Windows защищена от запуска незнакомых приложений» — нажмите «Всё равно запустить».
4. Дождитесь конца: в конце должно появиться сообщение `Готово: установлено 5 из 5 пакетов.` Если каких-то пакетов не хватило — экран покажет перечень с ссылками: скачайте недостающие файлы, положите рядом с `install_data.bat` и запустите его ещё раз.
5. Запустите `start.bat` (раздел 5.3) — откроется окно программы.

Пример вывода `install_data.bat`:

```text
=============================================================
 Установка пакетов данных Geant4 11.4.1
 Папка назначения: C:\Geant4\data
============================================================
  [распаковано] G4EMLOW.8.8 - папка: ...\data\G4EMLOW8.8
  ...
 Готово: установлено 5 из 5 пакетов.
 Теперь запустите start.bat.
=============================================================
```

Статус `[ок]` означает, что пакет уже стоит (например, его поставил сам установщик Geant4) — распаковывать его повторно не нужно.

**Как понять, что данных не хватает.** Если пакета нет, при расчёте Geant4 выдаёт ошибку вида `G4LEDATA data directory was not found` (или похожую, с другим именем переменной):

| Сообщение об ошибке | Чего не хватает |
|---|---|
| `G4LEDATA data directory was not found` | пакет G4EMLOW — таблицы электромагнитного взаимодействия |
| `G4RADIOACTIVEDATA ...` | пакет RadioactiveDecay — схемы распадов |
| `G4LEVELGAMMADATA ...` | пакет PhotonEvaporation — испускание γ-квантов |
| `G4ENSDFSTATEDATA ...` | пакет G4ENSDFSTATE — энергии уровней ядер |
| `G4PARTICLEXSDATA ...` | пакет G4PARTICLEXS — сечения взаимодействий |

Все эти ошибки лечатся одинаково: выполните порядок действий выше. Подробнее — раздел 7.2.

**Переменные среды — вручную ничего не нужно.** Каждый пакет должна сопровождать переменная Windows (например, `G4LEDATA` → путь к папке `G4EMLOW8.8`). `install_data.bat` и `start.bat` сами находят установленные папки данных и создают недостающие переменные. Например, `start.bat` печатает:

```text
[Исправлено] создана переменная G4LEDATA = C:\Geant4\data\G4EMLOW8.8
```

Распаковать архивы вручную (без `install_data.bat`) или посмотреть переменную вручную — раздел 8.3.

### 5.3. Первый запуск

**Дважды щёлкните по файлу `start.bat`.**

При первом запуске Windows может показать предупреждение «Windows защищена от запуска незнакомых приложений» — нажмите «Всё равно запустить» (этот файл — часть программы, он безопасен).

Что делает `start.bat`:

1. Проверяет, что установлен Python.
2. Проверяет, что Python собран с tkinter (нужен для окон интерфейса).
3. Проверяет, что установлен matplotlib.
4. Находит установленный Geant4 и проверяет, прописан ли он в системе (PATH).
5. Проверяет все пакеты данных Geant4: если папка с данными есть, а переменная не задана — создаёт её сама (печатает `[Исправлено] создана переменная ...`); если пакетов не хватает — предлагает скачать архивы и запустить `install_data.bat` (раздел 5.2).
6. Проверяет, что файл `build\Release\main.exe` на месте (архив распакован полностью).

Если **всё в порядке** — молча открывается окно программы «Программа Б — Генератор макросов». Если что-то не нашлось — `start.bat` напишет, чего именно не хватает и что сделать (список сообщений — в разделе 7).

   > **[Скриншот: окно «Программа Б — Генератор макросов»]**
   > *— окно программы, видны вкладки: Геометрия, Среда и материалы, Радионуклид, Распад, Получаемые значения, Запуск и вывод, Спектры.*

## 6. Программа: устройство и пример расчёта

### 6.1. Вкладки программы

| Вкладка | Что настраивается |
|---|---|
| Геометрия | форма ёмкости (цилиндр, стакан, пробирка), радиус, высота, толщина стеклянной стенки, сухой бортик |
| Среда и материалы | материал жидкости и стекла, их плотности |
| Радионуклид | выбор радионуклида; показываются период полураспада T½ и наличие данных Geant4 |
| Распад | режим расчёта: по числу распадов или по активности и времени облучения |
| Получаемые значения | какие поля выводить в результаты |
| Запуск и вывод | запуск симуляции, прогресс, просмотр результатов |
| Спектры | графики бета-спектров |

### 6.2. Пример: Lu-177 в стакане

Разберём полный расчёт: сколько поглощённой дозы получает вода в стакане от растворённого в ней Lu-177 (β⁻-излучатель, E_βmax ≈ 497 кэВ, один из основных нуклидов таргетной радиотерапии).

**Шаг 1 — Геометрия.** На вкладке «Геометрия»:

- Вариант ёмкости: **Стакан**
- Радиус: 2 см, Высота: 6 см (значения по умолчанию)
- Толщина стенки: 1,5 мм, Сухой бортик: 0 мм (по умолчанию)

Программа сразу покажет объём жидкости — для этих размеров 75,3982 см³.

**Шаг 2 — Среда и материалы.** Оставляем по умолчанию: жидкость — вода (G4_WATER, 1,000 г/см³), оболочка — стекло (SiO₂, 2,320 г/см³).

**Шаг 3 — Радионуклид.** На вкладке «Радионуклид» выберите из списка **Lu-177**. Программа покажет период полураспада (T½ ≈ 6,644 сут) и сообщение «Схема распада есть. Уровни дочерних есть.» — значит, данные Geant4 на месте.

**Шаг 4 — Распад.** Режим: **по числу распадов**, количество: `100000`.

**Шаг 5 — Запуск.** Вкладка «Запуск и вывод» → кнопка **«Запустить симуляцию»**. Следите за прогресс-баром. Для ста тысяч распадов на обычном компьютере требуется не больше пары секунд.

**Шаг 6 — Результаты.** После завершения внизу появится блок результатов (примерный вид; точные числа будут отличаться, так как генератор случайных чисел каждый раз другой):

### 6.3. Как читать результаты

| Поле | Что означает |
|---|---|
| `Number of decays` | сколько распадов просчитано — должно совпадать с заданным |
| `Volume`, `Material mass` | объём и масса жидкой среды — проверьте, что это ваши размеры |
| `Energy deposit (A)` | энергия, поглощённая жидкостью по Path A, МэВ |
| `Absorbed dose (A)` | **поглощённая доза по Path A, Гр (Грей)** — основной результат расчёта |
| `Decay energy (B)` | полная энергия, выделившаяся при всех распадах (вход в баланс), МэВ |
| `Escaped energy (B)` | энергия, покинувшая объём жидкости через её границу (в основном вторичными γ-квантами), МэВ |
| `Transferred (B)` | энергия, оставшаяся в жидкости по балансу (выход из баланса), МэВ |
| `Absorbed dose (B)` | поглощённая доза, посчитанная по Path B, Гр |
| `Cross-check (A-B)` | расхождение двух путей, МэВ. **Должно быть ≈ 0** — это ключевая проверка корректности: два независимых метода дали одинаковый результат |
| `Energy per decay` | средняя поглощённая энергия на один распад, МэВ |

Физический смысл: полная энергия распадов делится на поглощённую в жидкости и ушедшую наружу. Поглощённая часть (`Energy deposit (A)` ≈ `Transferred (B)`) — это в основном энергия β-частиц: их пробег в воде при E_βmax ≈ 497 кэВ около миллиметра, поэтому практически все они останавливаются в сантиметровом объёме и отдают энергию на ионизацию среды. Энергию же, покинувшую объём через границу жидкости (`Escaped energy (B)`), уносят преимущественно вторичные γ-кванта — прежде всего квант 208 кэВ дочернего ядра Hf-177: длина свободного пробега такого кванта в воде порядка 10 см, поэтому часть квантов проходит сквозь несколько сантиметров воды, не поглотившись. В этой геометрии наружу уходит около двух третей энергии распада, и поглощённая доза при 10⁵ распадов в 75 см³ воды — порядка 10⁻⁸ Гр.

### 6.4. Где сохраняются результаты

- В окне программы на вкладке «Запуск и вывод».
- В файле `results.txt` в папке программы — каждый запуск **дописывается** в конец файла, так что `results.txt` хранит историю всех расчётов.
- Рядом могут создаваться `beta_minus.txt` и `beta_plus.txt` — энергии бета-частиц, если на вкладке «Спектры» включена запись спектров.

## 7. Если что-то пошло не так

### 7.1. Сообщения start.bat

| Сообщение | Что сделать |
|---|---|
| `не найден Python` | Установите Python 3.12+ с <https://www.python.org/downloads/windows/>, включив «Add python.exe to PATH» (раздел 4.1) |
| `Python установлен без компонента tkinter` | Переустановите Python: запустите установщик повторно → «Modify» → включите «tcl/tk and IDLE» |
| `не установлен пакет matplotlib` | Откройте командную строку (Win+R, `cmd`) и выполните `py -m pip install matplotlib` (раздел 4.4) |
| `не найден Geant4` | Установите Geant4 11.4.1 (раздел 5), не забудьте отметить опцию добавления в PATH (шаг 5) и перезагрузите компьютер |
| `в установке Geant4 не хватает пакетов данных` | Скачайте архивы `.tar.gz` (ссылки — в разделе 5.2), положите их рядом с `install_data.bat`, запустите `install_data.bat` один раз, затем `start.bat` ещё раз |
| `не найден файл build\Release\main.exe` | Архив распакован не полностью — распакуйте заново (раздел 3.2) |

После исправления просто запустите `start.bat` ещё раз.

### 7.2. Ошибки Geant4 при расчёте

Эти ошибки появляются в самой программе (не в окне `start.bat`) — обычно если `start.bat` запускали не перед расчётом или обходили его:

| Сообщение | Что сделать |
|---|---|
| `G4LEDATA data directory was not found` | Не хватает пакета G4EMLOW — раздел 5.2: скачайте архив, положите рядом с `install_data.bat`, запустите `install_data.bat` и затем `start.bat` (переменная `G4LEDATA` пропишется сама) |
| `G4RADIOACTIVEDATA ...` / `G4LEVELGAMMADATA ...` | Не хватает пакетов RadioactiveDecay / PhotonEvaporation — раздел 5.2 |
| `G4ENSDFSTATEDATA ...` / `G4PARTICLEXSDATA ...` | Не хватает пакетов G4ENSDFSTATE / G4PARTICLEXS — раздел 5.2 |

Все подобные ошибки вида `... data directory was not found` лечатся одинаково: выполните порядок действий из раздела 5.2 — скачайте нужный архив, положите рядом с `install_data.bat`, запустите его, затем запустите `start.bat`.

### 7.3. Окно программы открылось, но что-то не так

| Ситуация | Причина и решение |
|---|---|
| Ошибка «Illegal application state» при запуске по своему макросу | Команды настройки геометрии и радионуклида должны стоять **до** строки `/run/initialize` |
| На вкладке «Радионуклид» написано, что данных Geant4 нет | Для этого нуклида в вашей установке Geant4 нет схемы распада — выберите другой нуклид из списка |
| Программа «зависла» на прогресс-баре | Возможно, задано очень много распадов — подождите или нажмите «Остановить симуляцию» и уменьшите число распадов |
| Окно start.bat открывается и тут же закрывается | Запустите start.bat через правую кнопку мыши → «Запуск от имени администратора». Если окно всё равно закрывается — запустите его из командной строки, чтобы увидеть текст ошибки: Win+R → `cmd` → перетащите файл `start.bat` в окно и нажмите Enter |

## 8. Приложение для опытных пользователей

Разделы ниже не нужны для обычной работы; они пригодятся, если потребуется запускать расчёты без интерфейса или разбираться в устройстве установки Geant4.

### 8.1. Пакетный режим (без графического интерфейса)

`main.exe` умеет работать по файлу-макросу:

```bat
build\Release\main.exe run.mac
```

Файл `run.mac` создаётся графическим интерфейсом автоматически при каждом запуске (его также можно сохранить кнопкой «Сохранить .mac»). Основные команды макроса:

```text
/myDetector/setGeometry        cylinder | beaker | tube
/myDetector/setRadius          2 cm
/myDetector/setHalfHeight      3 cm
/myDetector/setGlassWall       0.15 cm
/myDetector/setRim             0 cm
/myDetector/setGlassMaterial   G4_SILICON_DIOXIDE
/myDetector/setMaterial        G4_WATER
/mySource/setRadionuclide      71 177
/myOutput/enableAll
/mySpectrum/enable
/run/initialize
/process/had/rdm/thresholdForVeryLongDecayTime 1.0e+60 year
/run/beamOn 100000
```

Важно: команды `/myDetector/*` и `/mySource/setRadionuclide` должны стоять **до** `/run/initialize`.

### 8.2. Интерактивный режим с визуализацией

```bat
interactive.bat
```

или запустите `main.exe` без аргументов — откроется меню Geant4 с визуализацией геометрии (нужна поддержка OpenGL). Запускайте из папки программы: макросы `vis.mac` и `gui.mac` ищутся в текущем каталоге.

### 8.3. Ручная распаковка пакетов и переменные G4*DATA

**Распаковка вручную.** Обычно пакеты ставит `install_data.bat` (раздел 5.2) — ручной способ нужен, только если он по каким-то причинам не подходит. Файл пакета имеет расширение `.tar.gz`: Windows 11 открывает такие архивы прямо в Проводнике (правая кнопка → «Извлечь всё»), а в Windows 10 встроенной поддержки нет — там пригодится бесплатный 7-Zip (описан ниже). Способ, работающий в обеих системах, — команда `tar`, встроенная в Windows 10/11:

1. Откройте командную строку: **Win + R** → `cmd` → Enter (как в разделе 4.2).
2. Перейдите в папку данных Geant4 (путь подставьте свой):

   ```bat
   cd /d "C:\Geant4\data"
   ```

3. Распакуйте скачанный файл (путь подставьте свой, обычно это папка «Загрузки»):

   ```bat
   tar -xzf "C:\Users\<имя пользователя>\Downloads\G4EMLOW.8.8.tar.gz"
   ```

4. Повторите команду для каждого скачанного пакета — у каждого свой путь к файлу.

`start.bat` ищет папки в `<каталог Geant4>\data` - там, куда их ставит `install_data.bat`.

Если командная строка пугает — распакуйте через бесплатный архиватор 7-Zip: правая кнопка мыши по файлу → **7-Zip → «Извлечь сюда»**, затем перенесите появившуюся папку (например `G4EMLOW8.8`) в папку данных Geant4.

**Переменные среды.** Переменные окружения — это записи в системе Windows, которые указывают программам, где лежат файлы. Geant4 использует переменные вида `G4*DATA`: например, `G4RADIOACTIVEDATA` указывает на папку со схемами распадов, `G4LEVELGAMMADATA` — на папку с уровнями дочерних ядер.

Обычно переменные создаёт установщик Geant4, но при установке без пакетов данных их может не оказаться. **Проще всего не трогать их руками: запустите `install_data.bat`, а затем `start.bat`** — они сами найдут папки данных и создадут недостающие переменные (раздел 5.2).

Если нужно посмотреть или создать переменную вручную:

1. Нажмите **Win + R**, введите `sysdm.cpl`, нажмите Enter.
2. Вкладка «Дополнительно» → кнопка «Переменные среды…».
3. Найдите `G4RADIOACTIVEDATA` — она может находиться в блоке «Системные переменные» или «Переменные пользователя»; значением должен быть путь вида `...\data\RadioactiveDecay6.1.2`.

   > **[Скриншот: окно «Переменные среды» с подсвеченной G4RADIOACTIVEDATA]**

4. Если переменной нет, а папка с данными уже скачана — нажмите «Создать…» и укажите имя переменной и путь к папке. Но быстрее и надёжнее это делает `start.bat`.

### 8.4. Обновление и удаление

**Обновление:** скачайте новый архив релиза, распакуйте его поверх папки программы, заменив файлы. Файлы `run.mac` и `results.txt` при обновлении можно сохранить.

**Удаление:** просто удалите папку программы. Установленные Geant4, Python и matplotlib удаляются стандартными средствами Windows («Приложения»), если они больше не нужны.
